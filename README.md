# Raytracer demo
C++, Vulkanで開発したRay tracerです。依存はtiny_bvhとDear ImGuiです。
本アプリは、およそ２週間の間で開発が行われました。

## Ray tracerとは
画像を生成する技術です。その中さまざまなテクニックがありますが、本アプリでは以下の流れです。
1. 初期設定でvulkanのインスタンスを立ち上げます
2. 3D空間の中の球体の大きさ、物質、位置などを生成または読み込みます。
3. カメラの初期設定
4. アプリが終了するまで、繰り返し描画

描画のステップは基本的に
1. 乱数を生成するためのseedを計算
2. 描画するピクセルにあたり何本かの光線の位置、方向を計算
3. 光線の衝突判定、衝突位置の色と反射した後の方向を定める
4. 反射回数が上限でなければgoto 3
5. 光線の色を画面に書き込んでから、goto 1

1意外のステップはすべてGPUのシェーダーで行われています。

## ビルド方法
現在、プラットフォームはWindowsでコンパイラーはg++とmsvc (cl.exe) しか対応されていません。
尚、以下の条件を満たさないパソコンではコンパイル・実行が不可能なので予めご確認ください
- AVX2対応
- Vulkan 1.3対応

g++:
以下のコマンドを実行してください。

```
cmd
build
```

msvc:
clを有効にしてから、以下のコマンドを実行してください。
```
cmd
msvc_build
```

デフォルトでreleaseモードでコンパイルします。devモードでコンパイルがしたい場合は、g++で`build dev`を実行してください。

## 説明
- 現在、レンダーできるオブジェクトは球体しか対応していません。これは、開発期間を短めに抑えるためでした。
- 以下で使われる「サンプル」という言葉は基本的に光線のことを指します。画面のピクセルが有限である以上、継続的な空間を正確に再現することは不可能です。そのため、標本（サンプル）をとって推定するしかありません。具体的には各ピクセルから何本かの光線を放ち、「このピクセルの色はなんですか？」という問いを答えようとしています。

## editor内のパラメーターの説明
- 色の蓄積とは、過去フレームの描画結果を使うことによってより正確な画像を生成するテクニックです。より正確な画像を生成するためになるべく多いサンプルが望ましいですが、一つのフレームで採れるサンプルの数が限られています。よって、蓄積した過去サンプルを使います。
- アンチエイリアシングとは、シグナルの急な変化を和らげることです。これを無効にすると、物体の輪郭がカクカクとみえます。
- 層化サンプリングとは、サンプルを採る領域を層に分けて、それぞれの層から無作為にサンプルを抽出するテクニックです。結果、出力の収束速度が早まります。
- 重点サンプリングとは、出力画像に大きく影響を与えるもの（光を放つものなど）へ光線の方向を寄せることによって、出力の収束を早める技術です。これは3D描画で必要不可欠な手法とされています。
- ロシアンルーレットとは、出力画像に影響が弱い光線を無視して、収束を早める技です。
- 再構成フィルターとは、複数のサンプルで構成した（不完全な）画像をより完全に構成する技です。ただし、本アプリでは無効にしても出力画像に大した影響は出ません。
